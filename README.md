# Project Documentation

## MVP Feature

Structure

```
Laravel REST API
├── Auth admin/customer
├── Category product
├── Digital product
├── Product image/preview
├── Checkout/order
├── Payment integration
├── Download file setelah pembayaran
└── Admin management
```

- Produk tidak punya stok fisik seperti ecommerce biasa
- Produk butuh file digital/download link
- Produk bisa punya preview image
- Produk perlu kategori
- Pembeli hanya bisa download setelah pembayaran sukses
- Admin perlu upload/update product
